# M0 Foundation: task list

Milestone goal (design doc section 15): repository layout, Docker Compose with four
services, health page, Alembic baseline, job table and worker loop with a no-op job, CI and
CD workflows, pre-commit, gitleaks, the `ASSETS.md` check, README skeleton, ADRs 1 to 5.

**Done when:** CI is green, branch protection is on, `docker compose up` shows the board
and a no-op job completes.

## Notes

- VFS-61 and VFS-62 were added by the implementing agent. VFS-61 exists because the first
  session could not create the GitHub repository (see `docs/decisions-log.md`, D-001).
  VFS-62 comes from the owner's project standard (D-007).
- Until VFS-61 is resolved there is no remote, so no pull request and no CI run. Finished
  cards wait In review on stacked local branches, each verified with the local checks that
  exist at that point.
- Checks available per card grow as the milestone proceeds. Card 70 adds the CI jobs, and
  from then on the full list in design doc section 14.2 runs on every pull request.
